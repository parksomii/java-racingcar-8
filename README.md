# woowa precourse - week 2

## 1. 기능 요구 사항

초간단 자동차 경주 게임을 구현한다.

- 주어진 횟수 동안 n대의 자동차는 전진 또는 멈출 수 있다.
- 각 자동차에 이름을 부여할 수 있다. 전진하는 자동차를 출력할 때 자동차 이름을 같이 출력한다.
- 자동차 이름은 쉼표(,)를 기준으로 구분하며 이름은 5자 이하만 가능하다.
- 사용자는 몇 번의 이동을 할 것인지를 입력할 수 있어야 한다.
- 전진하는 조건은 0에서 9 사이에서 무작위 값을 구한 후 무작위 값이 4 이상일 경우이다.
- 자동차 경주 게임을 완료한 후 누가 우승했는지를 알려준다. 우승자는 한 명 이상일 수 있다.
- 우승자가 여러 명일 경우 쉼표(,)를 이용하여 구분한다.
- 사용자가 잘못된 값을 입력할 경우 `IllegalArgumentException`을 발생시킨 후 애플리케이션은 종료되어야 한다.

## 3. 기능 상세 명세

### **F-01. 자동차 이름 입력 받기**

- **설명**: 사용자에게 "경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)" 문구를 출력하고 입력을 받는다.
- **입력 예시**

    ```
    경주할 자동차 이름을 입력하세요.(이름은 쉼표(,) 기준으로 구분)
    pobi,woni,jun
    ```

### **F-02. 시도 횟수 입력 받기**

- **설명**: 사용자에게 "시도할 횟수는 몇 회인가요?" 문구를 출력하고 입력을 받는다.
- **입력 예시**

    ```
    시도할 횟수는 몇 회인가요?
    5
    ```

### **F-03. 자동차 이름 검증**

- **조건**:
    - 자동차 이름은 5자 이하만 가능
    - 빈 이름은 허용하지 않음
    - 앞뒤 공백은 trim 처리
- **예시**

| 입력                  | 검증 결과 | 설명              |
|---------------------|-------|-----------------|
| `"pobi,woni,jun"`   | 통과    | 정상적인 입력         |
| `"pobi,javaji,jun"` | 실패    | "javaji"가 5자 초과 |
| `"pobi,,jun"`       | 실패    | 빈 이름 포함         |
| `" pobi , woni "`   | 통과    | 공백 trim 처리      |

### **F-04. 시도 횟수 검증**

- **조건**: 시도 횟수는 양수여야 함
- **예시**

| 입력      | 검증 결과 | 설명          |
|---------|-------|-------------|
| `"5"`   | 통과    | 정상적인 양수     |
| `"0"`   | 실패    | 0은 허용하지 않음  |
| `"-1"`  | 실패    | 음수는 허용하지 않음 |
| `"abc"` | 실패    | 숫자가 아님      |

### **F-05. 자동차 객체 생성**

- **설명**: 검증된 자동차 이름들로 Car 객체들을 생성한다.
- **Car 클래스 필드**:
    - `name`: 자동차 이름
    - `movedDistance`: 현재 위치 (전진 거리)

### **F-06. 경주 게임 실행**

- **설명**: 지정된 횟수만큼 라운드를 진행한다.
- **진행 과정**:
    1. 각 라운드마다 모든 자동차에 대해 이동 조건 확인
    2. 이동 조건을 만족하면 movedDistance 증가
    3. 라운드 결과 출력

### **F-07. 랜덤 이동 조건**

- **조건**: 0~9 사이 랜덤 값이 4 이상일 때 전진
- **구현**: `Randoms.pickNumberInRange(0, 9) >= 4`

### **F-08. 경주 결과 출력**

- **형식**: 각 라운드마다 자동차별 이동 거리를 '-' 문자로 표시
- **예시**

    ```
    실행 결과
    pobi : -
    woni : 
    jun : -

    pobi : --
    woni : -
    jun : --
    ```

### **F-09. 우승자 결정**

- **조건**: 가장 많이 이동한 자동차(들)을 우승자로 결정
- **공동 우승**: 동일한 최대 거리를 이동한 자동차들

### **F-10. 우승자 출력**

- **형식**: "최종 우승자 : [우승자 이름들]"
- **예시**

| 상황    | 출력                   |
|-------|----------------------|
| 단독 우승 | `최종 우승자 : pobi`      |
| 공동 우승 | `최종 우승자 : pobi, jun` |

### **F-11. 예외 처리**

- **조건**: 잘못된 입력 시 `IllegalArgumentException` 발생
- **처리**: 예외 메시지 출력 후 프로그램 종료

### **F-12. 입력 검증 모듈 분리**

- **설명**: 입력 검증 로직을 `ErrorView` 클래스로 분리
- **역할**:
    - 기본 입력 검증 (빈 값, 공백 체크)
    - 에러 메시지 출력 및 예외 발생

### **F-13. 게임 로직 모듈 분리**

- **설명**: 경주 게임 로직을 `Racing` 클래스로 분리
- **역할**:
    - 자동차 관리 (`Participants` 클래스)
    - 라운드 진행
    - 우승자 결정

### **F-14. 출력 모듈 분리**

- **설명**: 결과 출력 로직을 `OutputView` 클래스로 분리
- **역할**:
    - 경주 결과 출력
    - 우승자 출력

### **F-15. 테스트 코드 작성**

- **설명**: 도메인 로직, 유틸리티, 예외 처리에 대한 포괄적인 테스트 작성
- **테스트 범위**:
    - **도메인 테스트**: Car, Racing, Participants, RoundResult
    - **유틸리티 테스트**: CarNameParser, RaceRoundParser
    - **예외 테스트**: RacingCarException

```

├── Application.java                   # 메인 클래스
├── controller/
│   └── RacingController.java          # 게임 컨트롤러
├── dto/
│   ├── RacingRequestDto.java          # 요청 DTO
│   └── RacingResponseDto.java         # 응답 DTO

├── model/
│   ├── car/
│   │   └── Car.java                   # 자동차 모델
│   ├── racing/
│   │   ├── Racing.java                # 경주 게임 모델
│   │   └── Participants.java          # 참가자 관리
│   └── result/
│       ├── CarRecord.java             # 자동차 기록

    └── ErrorView.java                 # 에러 뷰
```
